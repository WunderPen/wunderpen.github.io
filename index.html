WunderPen

AI-powered writing correction that lives in your menu bar and works everywhere you type. Select text, press a shortcut, and it’s instantly corrected and replaced—no copying, no pasting, no app switching.

System-wide everywhere

Works in any app—Mail, Notes, Pages, Slack, Chrome, VS Code, Terminal—via macOS Accessibility API. Smart dual-strategy replacement ensures compatibility, even with Electron apps.

Instant correction

Single keyboard shortcut (⌘⇧G or custom) corrects and replaces text in place. Five built-in modes: Correct Grammar, Improve Writing, Make Concise, Make Formal, Make Casual.

Unlimited custom prompts

Create your own AI transformations—translate, summarize, rewrite for any audience. Assign shortcuts to each for one-tap access.

Private and flexible

Run fully on-device with Ollama or use your OpenAI API key. No analytics, no telemetry, no accounts. Keys stored in macOS Keychain.

Effortless design

Menu bar only—no dock icon, no windows. Native feedback: spinning cursor, HUD, notifications. Setup in under a minute.

How it works

1. Install and grant permissions

Launch WunderPen, select your AI provider (Ollama or OpenAI), and enable Accessibility in System Settings. Done in 60 seconds.

2. Select text anywhere

Highlight text in any app—email, code, notes, browser, terminal.

3. Press shortcut

Hit ⌘⇧G (or custom). Text is processed and replaced instantly.

4. Customize as needed

Add prompts, assign shortcuts, switch providers—all from the menu bar.
